# 🎮 Platformer Game

Gioco platformer 2D sviluppato come progetto capolavoro per il PCTO.

## Tecnologie usate
- HTML5 Canvas
- CSS3
- JavaScript vanilla (nessuna libreria esterna)

## Come giocare
- **Frecce / WASD** → muoversi
- **Spazio / W / Su** → saltare (doppio salto disponibile!)
- **Salta sui nemici** dall'alto per eliminarli
- Raccogli tutte le monete e raggiungi la bandiera

## Funzionalità
- Movimento con fisica (gravità, inerzia)
- Doppio salto
- Nemici con pattuglia automatica
- Sistema di danno e invincibilità temporanea
- Particelle ed effetti visivi
- Camera che segue il giocatore
- HUD con salute e punteggio

## Struttura del progetto

├── style.css    # Stile e layout
├── game.js      # Logica del gioco
