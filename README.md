# 🎮 Platformer Game

Gioco platformer 2D infinito sviluppato come progetto capolavoro per il PCTO.

## Tecnologie usate
- HTML5 Canvas
- CSS3
- JavaScript vanilla (nessuna libreria esterna)

## Come giocare
- **Frecce / WASD** → muoversi
- **Spazio / W / Su** → saltare (doppio salto disponibile!)
- **Salta sui nemici** dall'alto per eliminarli
- Raccogli monete per aumentare il punteggio
- Ogni **250 punti** appare un boss — saltaci sopra per danneggiarlo!
- Raccogli i **cuori** che cadono per recuperare vita

## Funzionalità
- Movimento con fisica (gravità, inerzia)
- Doppio salto
- **Mondo infinito** — il livello si genera proceduralmente all'infinito
- Nemici con pattuglia automatica
- **Boss battle** ogni 250 punti, sempre più difficili (più HP, più veloci, proiettili più frequenti)
- **Cuori** che cadono dai boss sconfitti e casualmente dai nemici normali
- Sistema di danno e invincibilità temporanea
- Particelle ed effetti visivi
- Camera che segue il giocatore
- HUD con salute, punteggio e barra avanzamento boss
